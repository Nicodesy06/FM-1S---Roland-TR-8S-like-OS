PULSAR-8

TR-style rhythm machine firmware for the M-VAVE FM-1 — installer

1. Use Chrome or Edge on a computer. Connect the FM-1 with a USB data cable, directly (no hub), and switch it on. Close any other program that uses MIDI (DAW, M-UPGRADE, another installer tab).

2. Choose the firmware: the bundled PULSAR-8 package.

3. Press Install and allow MIDI access. Do not unplug until it says it is done (about 2 minutes).
